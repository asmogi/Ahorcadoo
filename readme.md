# Juego del Ahorcado

## Descripción

Aplicación web desarrollada en PHP que permite jugar al clásico juego del ahorcado.

## Requisitos

- PHP 8 o superior.
- Navegador web.
- Servidor PHP o servidor web Apache/Nginx configurado con PHP.

## Instalación

1. Clonar el repositorio.
2. Acceder a la carpeta del proyecto.
3. Ejecutar el servidor PHP local:

   php -S localhost:8000

4. Abrir en el navegador:

   http://localhost:8000

## Instrucciones del juego

1. El juego selecciona una palabra aleatoria.
2. El jugador debe introducir letras.
3. Cada error reduce el número de intentos disponibles.
4. Si descubre la palabra, gana la partida.
5. Si agota los intentos, pierde la partida.
